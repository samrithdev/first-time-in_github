Flexbox Layout ក្នុង CSS

Flexbox (Flexible Box Layout) គឺជាប្រព័ន្ធ Layout ដ៏មានឥទ្ធិពលដែលប្រើសម្រាប់រៀបចំ តម្រឹម និងបែងចែកលំហទំនេររវាងធាតុកូនៗ (Items) នៅក្នុង Container មួយយ៉ាងមានប្រសិទ្ធភាព និងឆ្លើយតបគ្រប់ទំហំអេក្រង់ (Responsive Layout)។

១ display: flex

ការកំណត់ display: flex លើធាតុឪពុក (Parent Container) នឹងធ្វើឱ្យធាតុកូនៗទាំងអស់នៅខាងក្នុងក្លាយជា Flex Items ដោយស្វ័យប្រវត្តិ ហើយពួកវានឹងតម្រៀបជាបន្ទាត់ផ្ដេក។

.container {
  display: flex;
}

១០ សេចក្តីសង្ខេប (Summary Key Points)

គន្លឹះសំខាន់ៗដែលត្រូវចងចាំ៖

  • • display: flex — បង្កើត Flex Container ដើម្បីគ្រប់គ្រងធាតុកូនៗ
  • • flex-direction — កំណត់ទិសដៅនៃ Main Axis (row, column)
  • • justify-content — តម្រឹមធាតុកូនតាម Main Axis (អ័ក្សដេក)
  • • align-items — តម្រឹមធាតុកូនតាម Cross Axis (អ័ក្សឈរ)
  • • flex-wrap — អនុញ្ញាតឱ្យធាតុកូនរុំធ្លាក់ជួរនៅពេលអស់ទំហំ
  • • gap — កំណត់គម្លាតរវាងធាតុកូនៗបានយ៉ាងងាយស្រួល
  • • flex-grow — កំណត់អត្រាលូតលាស់នៃធាតុកូននីមួយៗ
  • • Flexbox vs Grid: Flexbox ប្រើសម្រាប់ Layout 1 វិមាត្រ (1D) ចំណែក Grid ប្រើសម្រាប់ 2 វិមាត្រ (2D)
